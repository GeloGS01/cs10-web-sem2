# CS10 Web - Sem2

Grade 10 (10IS / 10IB) HTML, CSS and JavaScript, built in GitHub Codespaces.

## Your files
| File | What it does |
|------|--------------|
| `index.html` | the structure and content of your page |
| `style.css` | how it looks (already linked in `index.html`) |
| `script.js` | what it does (already linked in `index.html`) |

## Open your Codespace
1. Click the green **Code** button -> **Codespaces** tab -> **Create codespace on main**.
2. Wait for it to finish setting up (the first time takes 1-2 minutes).

## See your page
1. Open `index.html`.
2. Click the **Show Preview** button at the top-right of the editor (or right-click the file -> **Show Preview**).
3. The preview updates as you type.

To use the browser **Console** (for JavaScript), open the preview in its own Chrome tab, then press **Cmd + Option + J**.

## Check your setup
Open `setup-check/check.html` and show the preview. All three lines should say **PASS**.

## Saving your work
Your files stay in your Codespace, but **commit before you leave** so they are saved to GitHub for good:
1. Click the **Source Control** icon on the left (branch symbol).
2. Type a message like `Lesson 1 done`, then click **Commit**, then **Sync Changes**.

Then **sign out of GitHub** before you shut down the iMac.
